Amélioration continue & Open Source

Signaler une erreur, faire une suggestion ou contribuer

Ces syllabus sont des projets collaboratifs et évolutifs. Si vous repérez une coquille dans une démonstration, une erreur de calcul dans un corrigé, une figure imprécise ou si vous souhaitez suggérer un éclaircissement pédagogique, votre retour est très précieux ! Deux possibilités s'offrent à vous sur GitHub :

1. Ouvrir un Ticket (GitHub Issue)

La méthode la plus simple et rapide (aucune connaissance de LaTeX ou de Git n'est requise).

  1. Rendez-vous dans l'onglet Issues du dépôt concerné.
  2. Cliquez sur New issue.
  3. Précisez le numéro de chapitre, la page ou le numéro d'exercice, et décrivez la coquille ou votre suggestion (vous pouvez joindre une capture d'écran).

2. Proposer une Pull Request (PR)

Idéal si vous souhaitez corriger directement le fichier source LaTeX ou ajouter une figure TikZ / un développement.

  1. Créez une divergence (Fork) du dépôt ou modifiez directement le fichier .tex depuis l'interface web de GitHub.
  2. Soumettez une Pull Request vers la branche main.
  3. GitHub Actions vérifiera automatiquement que le document compile sans erreur, et le PDF sera mis à jour dès validation !

🛠️ Compilation LaTeX locale

Chaque syllabus peut être compilé localement à partir de son dépôt Git si vous disposez d'une distribution LaTeX complète (TeX Live ou MacTeX) incluant pdflatex, latexmk, tikz, pgfplots et tcolorbox : 

git clone https://github.com/epl-uclouvain-admission/syllabus_algebre.git
cd syllabus_algebre
latexmk -pdf -interaction=nonstopmode main.tex

Le fichier généré s'intitule main.pdf. Sur GitHub, chaque modification poussée sur la branche main régénère et publie automatiquement le PDF dans la section Releases (latest).

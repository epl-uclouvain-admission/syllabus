# Syllabus de Mathématiques — Examen d'admission Ingénieur Civil UCLouvain (EPL)

Bienvenue sur le dépôt portail regroupant les **trois syllabus de mathématiques** destinés à la préparation de l'**examen spécial d'admission aux études d'ingénieur civil** à l'[UCLouvain](https://uclouvain.be/fr/facultes/epl) (École Polytechnique de Louvain — EPL).

🌐 **Site web statique :** [`index.html`](./index.html) (déployé sur GitHub Pages : [https://epl-uclouvain-admission.github.io/syllabus/](https://epl-uclouvain-admission.github.io/syllabus/))

## 🤝 Signaler une erreur, faire une suggestion ou contribuer

Si vous repérez une coquille dans un énoncé, une démonstration, une figure ou un corrigé d'exercice, ou si vous souhaitez suggérer une amélioration pédagogique, vous pouvez contribuer directement sur le dépôt du syllabus concerné :

1. **Via un Ticket (*GitHub Issue*)** *(aucune connaissance de $\LaTeX$ requise)* :
   - [Ouvrir un ticket pour le **Syllabus d'Algèbre**](https://github.com/epl-uclouvain-admission/syllabus_algebre/issues)
   - [Ouvrir un ticket pour le **Syllabus d'Analyse**](https://github.com/epl-uclouvain-admission/syllabus_analyse/issues)
   - [Ouvrir un ticket pour le **Syllabus de Trigonométrie et de Géométrie**](https://github.com/epl-uclouvain-admission/syllabus_geometrie_trigonometrie/issues)

2. **Via une *Pull Request*** *(pour proposer directement une modification dans les fichiers sources `.tex`)* :
   - [Pull Requests — **Syllabus d'Algèbre**](https://github.com/epl-uclouvain-admission/syllabus_algebre/pulls)
   - [Pull Requests — **Syllabus d'Analyse**](https://github.com/epl-uclouvain-admission/syllabus_analyse/pulls)
   - [Pull Requests — **Syllabus de Trigonométrie et de Géométrie**](https://github.com/epl-uclouvain-admission/syllabus_geometrie_trigonometrie/pulls)
